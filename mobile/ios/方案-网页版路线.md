# 新方案：网页版路线（不用越狱）

## 关键洞察

pinning 存在于 **App 的原生网络栈（cronet，libsscronet）**。
但**浏览器用的是系统 TLS 栈，信任系统根证书**。

所以：**同一个服务，用浏览器打开，QX 就能 MITM。**

这条已经在你的手机上验证过了 —— httpbin 测试里 Safari 能正常解密并被改写
（出现了 `MITM_AND_REWRITE_BOTH_WORK`）。Safari 通，网页版就通。

## 汽水音乐有网页版

```
https://www.qishui.com/
```

实测（我这边 curl）：

```
www.qishui.com        200  0.45s
qishui.com            200  0.55s
标题：汽水音乐 - 抖音音乐版，随时随地懂你想听
主 JS：lf-luna.qishui.com/obj/music-luna-fe/luna/home/1.0.0.287/assets/index-*.js
```

是个 SPA，前端资源在 `lf-luna.qishui.com`，业务接口大概率也在 `*.qishui.com` 下。
**但没有 cronet，没有 pinning。**

## 怎么做

### 第 1 步：确认网页版能播

iPhone Safari 打开 https://www.qishui.com/ ，扫码登录，随便播一首歌。

- 能播 → 进第 2 步
- 提示"请在 App 内播放" → 这首是版权限制，换一首试；
  如果大部分都这样，网页版路线价值有限（见末尾局限）

### 第 2 步：找出网页版调用的接口域名

QX → 网络活动 → 顶部搜索框 → 输入 `qishui`

网页版的请求会带 `lf-luna` / `api*` 之类的前缀。记下**返回 JSON 的那个**
（不是 .js/.css/.png）。

### 第 3 步：把域名加进 MITM

```
[mitm]
hostname = <第2步找到的域名>
```

重启 VPN → 刷新网页 → 看 QX 里该请求的 **JS 计数是否 +1**。

- `+1` → 成功！这个域名没 pin（因为走浏览器）
- 没有 → 检查域名是否写对

### 第 4 步：挂上改写脚本

```
[rewrite_local]
^https?://<第2步的域名>/ url script-response-body https://cdn.jsdelivr.net/gh/shiwenxin123/qx-soda-vip@d26f032297b11305af2eb01933defd7a02a55ca8/soda_vip_unlock.js
```

## 这条路的优势

| | App | 网页版 |
|---|---|---|
| 证书 pinning | ✅ 有（cronet） | ❌ 没有（系统 TLS） |
| QX 能否 MITM | ❌ 失败 | ✅ 可以 |
| 需要越狱 | 是 | **否** |
| 功能完整度 | 100% | 约 50~70% |

## 局限（先知道再决定值不值）

1. **部分版权歌曲会提示"需在 App 内播放"** —— 网页版拿不到授权
2. 没有桌面歌词、没有本地缓存下载
3. 音质档位可能比 App 少
4. 推荐算法和 App 有差异

## 备选：网页版 + Mac

如果只是想在电脑上听，网页版 + QX 一样成立，而且比改 asar 更省事。
不过 Mac 版已经打好补丁了（`/Applications/汽水音乐 VIP.app`），不用折腾。

## 另外两个没试过的方向

### A. 安卓模拟器（Mac 上跑）

官网有安卓 APK。Mac 装 MuMu/Genymotion（自带 root），
里面装汽水 + Frida（过 pinning）+ mitmproxy。功能 100% 完整。

代价：占 2~4GB 内存、要配 Frida/证书，折腾度高。适合"就是要完整功能"的人。

### B. Windows 客户端

我在官网页面上发现了 Windows 版下载链接：

```
https://lf-luna-release.qishui.com/obj/luna-release/2.1.0/12292405/SodaMusic-v2.1.0-official-win32_x64.exe
```

如果它是 Electron 打包（大概率，和 Mac 版同源），那 Parallels 里装完
可以像 Mac 一样改 `app.asar`。你机器上有 Parallels Desktop，条件具备。

代价：要装 Windows 虚拟机、下载 100+MB 安装包、再逆向一遍（结构可能和 Mac 版一致，能复用补丁思路）。
