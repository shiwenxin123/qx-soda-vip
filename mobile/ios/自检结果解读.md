# 自检结果解读：MITM 通了，但重写没跑

页面里**没有** `MITM_SELFTEST` 字段 —— 但这不等于 MITM 不通。把三件事放在一起看：

| 观察 | 说明 |
|---|---|
| 打开 httpbin **没有证书警告** | QX 根证书**已被信任**（不信任会被拦「非私人连接」） |
| 之前把 qishui 加进 hostname → **App 立刻断网** | 说明 QX **确实在做 MITM**（否则加 hostname 不会有任何影响） |
| httpbin 页面内容**没被改** | 说明 **`[rewrite_local]` 那条规则没执行** |

结论：**MITM 是通的，卡在「重写规则没跑起来」**。
这是个好消息 —— 比 pinning 好解决得多。

## 按顺序查这四项（每项 10 秒）

### 1. iPhone Safari 能不能打开脚本地址


  （这三个我在电脑上测都是 200，`raw.gitmirror.com` 不通别用）

### 2. 「重写」总开关

QX → 设置（右下角齿轮）→ **重写** → 开关是否打开？

> 注意：QX 有两个开关，**MitM** 和 **重写**，是分开的。
> 只开 MitM 不开重写 → 能解密但脚本不执行，正好是你现在的现象。

### 3. 规则真的存进「当前配置文件」了吗

QX → 重写规则 → 看列表里有没有 `httpbin.org` 那条。

- 没有 → 编辑时「保存至」选错了配置文件，或者没点保存
- 有，但显示「需要更新」→ 点它重新保存一次

### 4. QX 日志里有没有报错

QX → 日志 → 找 `script` / `download` / `fail` 字样。
常见报错：`script download failed`（脚本拉不下来）、`no such file`（路径错）。

## 还有一个更稳的办法：把脚本放本地

如果 iPhone 访问 CDN 不稳定，别跟它较劲 —— QX 支持本地脚本：

1. QX → 设置 → **脚本**（或「重写 → 脚本管理」）
2. 新建脚本，把 `qx_mitm_selftest.js` 的内容整段粘进去，命名 `selftest`
3. 规则里脚本路径填 `selftest`（不带 http）

这样完全不依赖网络，一定能跑。**验证阶段建议直接用这个方式**，
等确认 MITM 链路没问题了，再换回远程地址。

## 为什么这件事值得较真

「重写不生效」和「pinning」是两个完全不同的问题：

| | 现象 | 解法 |
|---|---|---|
| 重写没跑 | 页面不变、无报错 | 开开关 / 修脚本地址 |
| pinning | App 断网、连接 0B/0B | iOS 不越狱无解 |

你现在是前者 —— **修好之后 VIP 和去广告都能做**。
所以别急着下结论说 iOS 不行，先把重写跑起来。

## 重写跑起来之后

1. 确认 httpbin 页面出现 `MITM_SELFTEST` → 链路通了
2. 换回汽水的域名，按 `qx-soda-mitm-staged-test.conf` 一次加一个
3. 如果 qishui 一加就断网 → 那才是 pinning

## ★ 已确认根因：jsDelivr 缓存了旧版脚本

你 01:14 打开脚本地址时，页面显示的是 **v1 的代码**（结尾是 `$done({});`，
没有注入 `MITM_SELFTEST` 的那段）。而本地/仓库里已经是 v2 了。

实测对比（同一时刻）：

```
@main   → grep MITM_SELFTEST = 0   ← 旧版 v1（被缓存）
@6124b7c→ grep MITM_SELFTEST = 1   ← 新版 v2（正确）
```

所以：**脚本能下载，但下载到的是旧版**。旧版只做 `$done({})`，不改 body，
页面自然看不出任何变化 —— 这**不能证明 MITM 不通**。

### 已处理

1. 对 `@main` 执行了 jsDelivr purge（返回 `status: finished`）
2. 重新校验，三个脚本现在都与本地**逐字节一致**

### 为了不再踩这个坑：用固定 commit 地址

jsDelivr 对 `@main` 有缓存，改用 commit SHA 就永远命中正确版本：

```
https://cdn.jsdelivr.net/gh/shiwenxin123/qx-soda-vip@6124b7c3c64eec9a99c41c68f37fe9896b6c7201/mobile/ios/qx_mitm_selftest.js
```

以后我改脚本会给你新的 SHA，或者你自己在仓库 commit 页面复制。

### 重新自检

把规则里的地址换成上面这个 SHA 版（或 purge 后的 @main），保存 → 重启 VPN →
Safari 刷新 `https://httpbin.org/get`。
